# 🤖 5lbs Wedge Sumo Bot

![5lbs Sumo Bot](https://media.printables.com/media/prints/1898676/rich_content/74e3989b-6a4d-488f-b5dc-06f7d1c23a19/5lbs_sumo_bot_1.png)

## 💡 What is this?

This is my **5lbs 3D-printable Wedge Sumo Bot**, designed entirely in **Autodesk Fusion 360**.

The main feature of this robot is its **30-degree inclined front wedge**, which is designed to get underneath an opponent and push it out of the sumo ring.

For the electronics, I'm using an Arduino Uno with an L293D motor driver shield, two TT gear motors, and a 2S Li-ion battery pack.

Basically, it's a small pushing robot built for sumo competitions! 🥊

## 🎯 Why I Made It

Honestly, I wanted to build a simple combat robot to improve my mechanical design and CAD skills.

I've always been interested in robotics, especially the mechanical side of things. Instead of just watching tutorials, I wanted to design something myself, understand how each component fits together, and learn through actual building.

This is still a work in progress, and I'm learning something new with every design change and test run.

My main goals were:
- Improve my Fusion 360 skills.
- Learn how to design a functional robot chassis.
- Understand motor placement and mechanical integration.
- Experiment with wedge geometry and pushing mechanisms.
- Build something that can eventually compete in a sumo competition.

## 🛠️ How I Designed It

I started by designing the chassis in Fusion 360.

First, I created the bottom platform and added the mounting positions for the motors and electronics. Then, I imported the 3D models of the TT motors, wheels, Arduino Uno, and L293D motor driver shield to check how everything would fit inside the robot.

After that, I started working on the side structures.

I created a sketch around the motor area and extruded it to form a box-like chassis. Once one side was completed, I designed the front wedge with a **30-degree inclination** and used the mirror feature to create the opposite side.

Finally, I created another sketch on the top and designed the top plate to cover the electronics and complete the chassis.

And that's how the basic design came together! :)

## 🔩 Assembly Guide

Ready to build your own 5lbs Wedge Sumo Bot? Follow these steps.

### Step 1: Print the Chassis and Top Plate

![Sumo Bot Chassis](https://media.printables.com/media/prints/1898676/rich_content/1bf973d4-c44e-45f3-b6be-62d8ee396d3a/5lbs_sumo_chassis.png)

![Sumo Bot Top Plate](https://media.printables.com/media/prints/1898676/rich_content/ccac7798-5a7d-4681-859d-ee3d778aeebe/5lbs_sumo_bot_top.png)

- 3D-print both the main chassis and the top plate.
- Clean up any leftover printing material.
- Check that all mounting holes and standoffs are clear.
- Make sure the motor mounting positions are properly aligned.

### Step 2: Install the TT Motors

- Take the two TT gear motors.
- Mount one motor on each side of the chassis.
- Secure them using screws.
- Attach the wheels to both motor shafts.
- Make sure both wheels rotate freely.

### Step 3: Mount the Arduino Uno

- Place the Arduino Uno onto the chassis standoffs.
- Align the USB port with the opening on the side of the chassis.
- Secure the board properly.

### Step 4: Install the Motor Driver Shield

- Place the L293D motor driver shield on top of the Arduino Uno.
- Make sure all the pins are correctly aligned.
- Press it down carefully to establish a proper connection.

### Step 5: Connect the Electronics

Now it's time to connect everything!

- Connect both TT motors to the L293D motor driver shield.
- Connect the 2S battery pack to the power input.
- Connect the main power switch.
- Organize the wires inside the chassis.
- Double-check the polarity and connections before powering it on.

### Step 6: Upload Your Code

- Connect the Arduino Uno to your computer using a USB cable.
- Upload your Arduino program.
- Configure the motor control pins according to your wiring.
- Once the code is uploaded, disconnect the USB cable and prepare for testing.

**The coding part is yours!** 🚀

### Step 7: Final Assembly and Testing

- Place the top plate onto the chassis.
- Secure it using screws.
- Check that all wires are properly organized and nothing interferes with the wheels.
- Turn on the robot and test its movements.

Test the following:
- Forward movement
- Reverse movement
- Left and right turns
- Both motors working correctly

And that's it! Your 5lbs Wedge Sumo Bot is ready for its first test run! 🏁
